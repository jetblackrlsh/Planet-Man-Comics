# Planet-Man Art Style Guide

This document is binding project instruction for agents handling Planet-Man image generation tasks. Before generating, regenerating, editing, or replacing any Planet-Man artwork, read and follow this guide alongside the relevant issue script, character bible, and reference-image notes.

All Planet-Man art must be AI generated using the built-in in-chat AI image generation capability. Do not use hand-drawn art, manually composited artwork, stock art, non-AI illustration, or external image-generation workflows as the source of final series art unless the project direction is explicitly changed.

Whenever an issue introduces a new named character or named setting, create a dedicated reference image for that character or setting and add it to the `Reference Images/` directory. Also add the corresponding generation prompt to `Reference Images/reference-image-prompts.md` using the next available reference number, so future issues can preserve continuity.

The visual style is realistic candid photography. Characters, settings, powers, costumes, props, logos, cosmic elements, and comic pages should look as though they were captured by a real camera in an actual physical environment. Use natural or believable practical lighting, real materials, grounded textures, imperfect handheld framing, documentary immediacy, and photoreal effects.

Impossible subjects should still feel physically present. Miniature planets, divine stone skin, living wood bodies, molten eyes, cosmic fabric, disaster bodies, magic, dreams, and scale-changing effects should be treated like photographed physical phenomena or restrained photoreal VFX inside real spaces.

For generated comic pages, the target aspect ratio is 4:5 portrait. Caption text should appear as plain caption copy inside the generated page art, without numbered captions and without using a `Speaker Name: ` prefix or any equivalent speaker-label format to designate who is speaking.

Avoid cartoon rendering, anime, painted illustration, comic-book linework, airbrushed fantasy art, glossy superhero poster polish, overdesigned studio composition, visible watermarks, visible logos, and readable incidental text unless exact readable story text is intentionally part of a generated comic page.
